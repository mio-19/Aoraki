== Overview

This project is a smartwatch-dedicated operating system built on top of link:https://nixos.org/nixos/[NixOS Linux],
link:https://nixos.org/nixpkgs/[Nixpkgs], and the upstream hardware and userland achievements of link:https://asteroidos.org/[AsteroidOS].

Unlike generic mobile Linux distributions designed for smartphones, tablets, or laptops, this system is engineered specifically from the ground up for wearable constraints:

* **Watch Display Geometries**: Native support for circular screens (e.g. 400x400, 384x384), square displays (e.g. ZenWatch 320x320), and "chin" (flat-tire) displays (e.g. Moto 360).
* **Wearable Input Systems**: Rotary encoder crown dials, multi-button navigation, and wrist gesture detection.
* **Wrist Power & Thermals**: Aggressive Always-On Display (AOD) ambient mode, OLED burn-in pixel shift protection, aggressive autosuspend, and wrist thermal thresholds.
* **AsteroidOS Userland Integration**:
  ** *`asteroid-launcher`*: Fast Wayland compositor and shell with 4-way gesture navigation (quick settings, notification center, today overview, app launcher).
  ** *`qml-asteroid`*: QML touch toolkit tailored for round and small square screens.
  ** *`asteroid-btsyncd`*: Bluetooth Low Energy sync daemon compatible with the AsteroidOS Sync companion app (Android/iOS) and Gadgetbridge for phone notifications, time sync, weather, and media control.
  ** *AsteroidOS Core Apps*: Settings, Stopwatch, Timer, Alarm Clock, Calculator, Calendar, Weather, Music remote, Compass, Flashlight.

== Quick Start

=== Evaluating a Watch Configuration

You can evaluate the system derivation for either target watch:

[source,bash]
----
# Evaluate Fossil Gen 6 (on hand)
nix-instantiate --eval -E '(import ./default.nix { device = "fossil-hoki"; }).config.mobile.device.name'

# Evaluate OPPO Watch 46mm OW19W8 (target)
nix-instantiate --eval -E '(import ./default.nix { device = "oppo-beluga"; }).config.mobile.device.name'
----

=== Building the Smartwatch Environment

To build a full flashable image with the Wayland desktop environment for your watch:

* **For Fossil Gen 6 (`fossil-hoki`)**:
+
[source,bash]
----
nix-build examples/asteroid --argstr device fossil-hoki -A outputs.default --keep-going
----

* **For OPPO Watch 46mm OW19W8 (`oppo-beluga`)**:
+
[source,bash]
----
nix-build examples/asteroid --argstr device oppo-beluga -A outputs.default --keep-going
----

Once the build finishes, the output artifacts are linked in `./result`:

* `result/boot.img`: Linux kernel (with appended DTB) and stage-1 initramfs.
* `result/system.img`: Ext4 root filesystem (`LABEL=NIXOS_SYSTEM`) containing the complete Nix store and system generation.
* `result/flash-critical.sh`: Automated helper script executing the target fastboot commands for critical boot partitions.

=== Flashing via Fastboot

==== Fossil Gen 6 (`fossil-hoki` — On Hand)

[source,bash]
----
# 1. Put Fossil Gen 6 into fastboot mode:
# Either from an active ADB connection:
adb reboot bootloader
# Or power off the watch, place on the charging puck, and hold the crown + bottom buttons simultaneously.

# 2. Verify connection on host PC:
fastboot devices

# 3. Unlock bootloader (if not already unlocked):
fastboot flashing unlock

# 4. Flash Linux kernel and stage-1 initramfs to both A/B slots:
fastboot flash --slot=all boot result/boot.img
# (Alternatively, run: ./result/flash-critical.sh)

# 5. Flash root filesystem to the userdata partition (recommended to utilize full eMMC capacity):
fastboot flash userdata result/system.img

# 6. Wipe stale Android cache (recommended when first installing over Wear OS):
fastboot format cache

# 7. Reboot into NixOS:
fastboot reboot
----

TIP: To avoid USB pogo-pin drops during flashing, you can boot TWRP and use `./bin/resilient-flash result/system.img --boot-img result/boot.img --reboot`.

==== OPPO Watch 46mm (Model OW19W8 / `oppo-beluga` — Target)

[source,bash]
----
# 1. Put OPPO Watch into fastboot mode:
# Either from ADB:
adb reboot bootloader
# Or power off the watch and hold both the Upper Button and Lower Button simultaneously.

# 2. Verify connection on host PC:
fastboot devices

# 3. Flash Linux kernel and stage-1 initramfs:
fastboot flash boot result/boot.img

# 4. Flash root filesystem to userdata partition:
fastboot flash userdata result/system.img

# 5. Wipe cache and reboot:
fastboot format cache
fastboot reboot
----

== System Updates over USB Gadget / SSH

One of the key benefits of NixOS is atomic, rollback-capable system updates over USB or Wi-Fi without needing to reflash partitions in fastboot.

=== USB Networking Setup

When booted, the smartwatch automatically exposes a USB Ethernet Gadget interface with a static IPv4 address:

* **Watch IP**: `192.168.2.15`
* **Host Subnet**: `192.168.2.0/24`

Configure the USB network interface on your host machine:

[source,bash]
----
# Identify USB network interface (e.g., usb0, enp0s20f0u...)
ip link

# Assign host IP and bring interface up
sudo ip addr add 192.168.2.14/24 dev usb0
sudo ip link set usb0 up

# Test connectivity
ping -c 3 192.168.2.15
----

=== Connecting via SSH

Open a remote shell on the watch:

[source,bash]
----
ssh root@192.168.2.15
----

=== Updating Live System Configurations

To deploy updates, bug fixes, or new packages directly to the running smartwatch:

==== Option A: Direct NixOS Rebuild over SSH

[source,bash]
----
nixos-rebuild switch \
  -I nixos-config=./examples/asteroid/configuration.nix \
  --target-host root@192.168.2.15
----

==== Option B: Closure Copy & Instant Activation

[source,bash]
----
# 1. Build updated toplevel closure on host for fossil-hoki
nix-build examples/asteroid --argstr device fossil-hoki -A build.toplevel --keep-going

# 2. Copy the store closure to the watch
nix-copy-closure --to root@192.168.2.15 ./result

# 3. Activate the new generation on the watch
ssh root@192.168.2.15 "nix-env -p /nix/var/nix/profiles/system --set \$(readlink -f result) && /nix/var/nix/profiles/system/bin/switch-to-configuration switch"
----

== Application Suite

The environment includes a rich catalog of touch-optimized smartwatch applications:

* *`asteroid-browser`*: Lightweight web browser with integrated virtual keyboard support and wearable quick-links.
* *`asteroid-telegram`*: Native smartwatch Telegram client with touch-friendly chat lists, message history, voice reply integration, and quick canned responses.
* *`asteroid-virtualkeyboard-rime`*: On-screen touch keyboard featuring integrated link:https://rime.im/[RIME] input method engine support and bundled Chinese dictionaries.
* *`asteroid-beatfork`*: High-precision metronome and chromatic tuning fork with Tack-inspired tap tempo calculation, accented subdivisions (1/4, 2/4, 3/4, 4/4, 6/8), concentric visual pulse ring, and distinct smartwatch haptics.
* *`asteroid-map`*: Touch GPS map viewer featuring offline tile cache persistence, compass heading orientation, and circular edge controls.
* *`asteroid-music`*: Media playback remote controller for phone media players via Bluetooth MPRIS, enhanced with standalone YouTube Music streaming directly on the watch.
* *`asteroid-2048`*: Classic sliding-tile puzzle game packaged directly from upstream with Qt 6 touch acceleration.
* *Core Utilities*: Stopwatch, Countdown Timer, Alarm Clock, Calculator, Weather, Compass, Flashlight, and Heart Rate Monitor.

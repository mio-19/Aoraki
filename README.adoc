== Overview

This project is a smartwatch-dedicated operating system built on top of link:https://nixos.org/nixos/[NixOS Linux],
link:https://nixos.org/nixpkgs/[Nixpkgs], and the upstream hardware and userland achievements of link:https://asteroidos.org/[AsteroidOS].

Unlike generic mobile Linux distributions designed for smartphones, tablets, or laptops, this system is engineered specifically from the ground up for wearable constraints:

* **Watch Display Geometries**: Native support for circular screens (e.g. 400x400, 384x384), square displays (e.g. ZenWatch 320x320), and "chin" (flat-tire) displays (e.g. Moto 360).
* **Wearable Input Systems**: Rotary encoder crown dials, multi-button navigation, and wrist gesture detection.
* **Wrist Power & Thermals**: Aggressive Always-On Display (AOD) ambient mode, OLED burn-in pixel shift protection, aggressive autosuspend, and wrist thermal thresholds.
* **AsteroidOS Userland Integration**:
  ** *`asteroid-launcher`*: Fast Wayland compositor and shell with 4-way gesture navigation (quick settings, notification center, today overview, app launcher).
  ** *`qml-asteroid`*: QML touch toolkit tailored for round and small square screens.
  ** *`asteroid-btsyncd`*: Bluetooth Low Energy sync daemon compatible with the AsteroidOS Sync companion app (Android/iOS) and Gadgetbridge for phone notifications, time sync, weather, and media control.
  ** *AsteroidOS Core Apps*: Settings, Stopwatch, Timer, Alarm Clock, Calculator, Calendar, Weather, Music remote, Compass, Flashlight.

== Quick Start

=== Evaluating a Watch Configuration

You can evaluate the system derivation for any supported watch:

[source,bash]
----
# Evaluate Google Pixel Watch 2
nix-instantiate --eval -E '(import ./default.nix { device = "google-aurora"; }).config.mobile.device.name'

# Evaluate Fossil Gen 6
nix-instantiate --eval -E '(import ./default.nix { device = "fossil-hoki"; }).config.mobile.device.name'
----

=== Building the AsteroidOS Smartwatch Environment

To build a full flashable image with the AsteroidOS Wayland desktop environment for your watch:

[source,bash]
----
nix-build examples/asteroid --argstr device google-aurora -A outputs.default
----

=== Flashing Boot Artifacts

Fastboot-capable watches produce fastboot-ready boot images:

* **Android Header v4** (e.g. Pixel Watch 2):
  [source,bash]
  ----
  fastboot flash --slot=all boot boot.img
  fastboot flash --slot=all vendor_kernel_boot vendor_kernel_boot.img
  fastboot flash --slot=all init_boot init_boot.img
  ----
* **Standard Android Bootimg** (e.g. Fossil Gen 5/6, Huawei Watch, LG Watch Urbane):
  [source,bash]
  ----
  fastboot flash boot boot.img
  ----

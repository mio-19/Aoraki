= NixOS for Smartwatches: Project Roadmap & TODO
:toc: left
:toclevels: 3
:icons: font

This document tracks upcoming milestones, architectural enhancements, hardware enablement tasks, and community feature requests for running declarative NixOS on wearable hardware.


== Display, Compositor & UI Adaptations

* [x] *Stage-1 AsteroidOS Parity & Seamless Handover*:
** Implemented `sticky` splash handover (`mobile.boot.stage-1.gui.sticky`) so the boot logo remains visibly drawn on `/dev/fb0` across `switch_root` without screen blackout.
** Added physical smartwatch button interception (`KEY_POWER` / stem button `0x74`, `KEY_BACK`, `BTN_TRIGGER_HAPPY`) to `Hal::Recovery::KEYS` with a 1-second polling window (`waitmidbutton` parity) to invoke the Generation Selection & Recovery menu.
** Optimized Stage-1 udev with subsystem-filtered triggers (`block`, `input`, `graphics`) and fast settle, bypassing synthetic Android sysfs delays.
** Clamped LVGUI window base elements to screen width with dynamic circular safe-insets ($14.64\%$) to prevent viewport overflow on narrow smartwatch displays.
* [ ] *Circular AMOLED Visual Optimization*:
** Ensure all stage-1 LVGL applets (`boot-splash`, `boot-error`, `boot-selection`) adapt gracefully to circular viewports with circular-safe margins and centered layouts.
** Add burn-in protection shifts and low-power Ambient / Always-On-Display (AOD) watchfaces.
* [x] *Hardware Rotary Crown Integration*:
** Mapped hardware crown rotational encoder events (`/dev/input/event1` relative axis) via `-plugin evdevmouse:/dev/input/event1` in `asteroid-launcher` through `$LIPSTICK_OPTIONS`.
* [ ] *On-Screen Virtual Keyboard Enhancements*:
** Optimize RIME input method suggestions and key layout spacing for 400x400+ circular displays.
** Provide flick-to-type or swipe input support.

** Verify and harden BLE synchronization between `asteroid-btsyncd` on the watch and the Android companion app:

* [ ] *WLAN & Network Management*:

== Kernel, Storage & Stage-1 Boot Architecture

* [ ] *Stage-1 Partition Discovery & UDev Trigger Upstreaming*:
** Android vendor kernels feature synthetic sysfs nodes (such as `/sys/class/android_usb`) that reject synthetic `udevadm trigger --action=add` uevents with `EINVAL` (exit code 1). Upstream a filter or ignore rule in Mobile NixOS `boot/init/tasks/udev.rb` instead of rescuing generic `CommandError`.
** *Refactor device-specific partition fallback in `boot/init/tasks/udev.rb`*: Currently, `ensure_partition_links()` contains a temporary fast-development fallback for `/dev/mmcblk0p50` (the `userdata` partition index on Fossil Gen 6 `fossil-hoki`). Once upstream 32-bit ARM downstream kernel udev rules reliably parse GPT partition table labels (`/dev/disk/by-label/NIXOS_SYSTEM`) or dynamic `PARTNAME` scanning from sysfs is fully stabilized across all watch models, remove this device-specific node reference from the generic `udev.rb` task.
* [ ] *Btrfs Transparent Compression Evaluation on Smartwatches*:
** Downstream Qualcomm 4.14 vendor kernel currently fails to mount Btrfs root partitions (`mount -t btrfs`), necessitating ext4 as the standard root filesystem.
** Investigate backporting modern Btrfs fixes or kernel upgrade (4.19 / mainlined kernel) to allow zstd transparent rootfs compression on eMMC.
* [x] *Stage-2 Graphical Compositor Configuration on Qualcomm MDSS fbdev*:
** Configured `asteroid-launcher` (Lipstick QtWayland compositor) to render on Qualcomm Mobile Display Subsystem (`/dev/fb0`) via `linuxfb:fb=/dev/fb0` with `QT_ENABLE_HIGHDPI_SCALING=0`.
** Enabled `mobile.quirks.fb-refresher` (`msm-fb-refresher --loop`) and `qualcomm.fb-notify` for continuous command-mode DSI panel redraws.
** Initialized display unblanking (`echo 0 > /sys/class/graphics/fb0/blank`) and backlight brightness (50%) in `boot.postBootCommands`.
** Configured `underclock-hoki` service to restore low-power sleep modes (`sleep_disabled = 0`, `idle_enabled = 0`), switch CPU governor to `ondemand`, and park secondary cores post-boot.

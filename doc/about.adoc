= About NixOS for Smartwatches
include::_support/common.inc[]

This project is a dedicated smartwatch operating system built on top of link:https://nixos.org/nixos/[NixOS Linux],
link:https://nixos.org/nixpkgs/[Nixpkgs] and link:https://nixos.org/nix/[Nix],
incorporating the hardware adaptations and software stack of link:https://asteroidos.org/[AsteroidOS].

In four words: _“NixOS, on your wrist”_.

== Goals

The goal is to provide a purely declarative, robust, and reproducible operating system for smartwatches.
Key focuses include:
- Native watch display geometry handling (round, square, chin displays).
- Low-memory tuning and aggressive power management suited for all-day wearable battery life.
- Seamless companion pairing and notification synchronization via AsteroidOS BLE protocols.
- Reproducible device configurations for watches across multiple generations of Wear OS hardware.

== Prior work and thanks

This project directly adapts and builds upon the pioneering achievements of:
- The link:https://asteroidos.org/[AsteroidOS Project] for their extensive work reverse engineering smartwatch hardware, writing the Asteroid UI, and maintaining kernel trees.
- The link:https://mobile-nixos.github.io/[Mobile NixOS project] for initial mobile abstractions on NixOS.
